# Predicting Target App for Search Using Decision Tree and Deep Learning Models with Contextual Usage Data

This study aims to enhance mobile search experiences by improving the accuracy of target app prediction. Building upon the research of Aliannejadi et al. (2018) which utilised real-time app usage context and app pre-classification labels, we developed an AI model capable of predicting the app a user is most likely to use for a given search query, based on the search text and personalised data. Utilising the ISTAS dataset, which offers user search queries paired with contextual app usage data, we analysed relationships within the data and evaluated different feature combinations using decision tree models and deep learning MLP models. We proposed a method that combines BERT-processed word embeddings of the search text with real-time app usage data, enhancing the model's understanding by incorporating app label data not initially present in the dataset. Our models performed optimally on individual user data, with the best-performing XGBoost model achieving approximately 88% prediction accuracy and about 96% Top 3 accuracy. While the model's versatility across all user data in the ISTAS dataset was moderate and slightly below the original authors' results, this discrepancy was mainly due to differences in weighting strategies and model selection. The dependency on user behaviour data also resulted in weaker performance when user data was sparse.
Overall, this study provides a feasible technical validation for recommending target apps by integrating user app usage data into decision tree models. We encourage future researchers to expand and optimise the model according to specific application requirements.
